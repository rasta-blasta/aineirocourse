# Внутри нейросети · Inside a Neural Network

**Интерактивный курс о том, как на самом деле работают нейросети и большие языковые модели** — для людей без технического образования. Один HTML-файл, ноль серверов, пять языков.

**Открыть курс:** https://ВАШ-ЛОГИН.github.io/neurocourse/ ← замените на свой адрес после публикации

*An interactive course on how neural networks and LLMs actually work — for non-technical readers. A single HTML file, zero servers, five languages: Русский · English · Français · 中文 · العربية.*

---

## Что внутри

- **11 модулей** — от цепей Маркова до трансформеров, RLHF, температуры, RAG, агентов и открытых весов
- **10 интерактивных демонстраций** — генератор Маркова, нейрон с ползунками, градиентный спуск, карта эмбеддингов, механизм внимания, рулетка температуры, RAG-поиск и другие
- **Игра «Собери нейросеть»** — соберите и обучите настоящую нейросеть прямо в браузере: она учится распознавать цифры на 2 500 настоящих рукописных образцах (или на печатных шрифтах — сравните!) и распознаёт то, что вы нарисуете мышью
- **132 вопроса** в тестах, повторные проверки для закрепления, упражнения «своими словами», итоговый экзамен
- **5 языков** с переключателем в меню; арабская версия — с письмом справа налево

## Как это устроено

Весь курс — один файл `index.html` (~2 МБ): тексты, тесты, демонстрации, игра, переводы и датасет рукописных цифр. Никаких фреймворков, серверов и внешних запросов (кроме шрифтов Google Fonts). Подробности — в [инфографике](infografika.html).

**Прогресс** каждого читателя хранится в его браузере (localStorage) и никуда не отправляется. Вернулись через неделю — всё на месте. Для переноса на другое устройство есть «Сохранить прогресс в файл» / «Загрузить прогресс из файла» внизу меню. Прогресс общий для всех языков.

## Запуск локально

Скачайте `index.html` и откройте двойным кликом. Всё.

## Пересборка из исходников

Папка [`src/`](src/) содержит исходники: тексты модулей (`module*.json`), вторые банки вопросов и упражнения (`extra*.json`), переводы (`en-*`, `fr-*`, `zh-*`, `ar-*`), данные демок, датасет цифр и шаблон движка. Сборка (Windows PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -File src/build.ps1
```

Проверка целостности перевода: `powershell -File src/validate-lang.ps1 -lang en`
